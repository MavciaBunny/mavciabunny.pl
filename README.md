# MavciaBunny — Luxury Black & Silver

Nowa wersja strony w stylu black / silver / marble luxury.

## Pliki

- `index.html` — cała treść strony
- `style.css` — wygląd
- `script.js` — delikatne animacje
- `CNAME` — domena `mavciabunny.pl`
- `images/bunny-mask.png` — latająca maska
- `images/bunny.jpeg` — zdjęcie profilowe
- `images/featured.jpg` — szerokie zdjęcie

## WAŻNE

W paczce znajdują się neutralne pliki zastępcze dla `bunny.jpeg` i `featured.jpg`.
Po wrzuceniu paczki na GitHub zamień je na swoje właściwe zdjęcia, zachowując dokładnie te nazwy:

`images/bunny.jpeg`

`images/featured.jpg`

Nie zmieniaj nazw `bunny-mask.png`, `index.html`, `style.css` ani `script.js`.
