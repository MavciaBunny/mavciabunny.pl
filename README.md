# MavciaBunny — GitHub Pages

## Co znajduje się w paczce
- `index.html` — cała strona
- `style.css` — wygląd, responsywność i animacje
- `script.js` — drobne zachowanie strony
- `assets/` — zdjęcia

## Zdjęcia
W folderze `assets` podmień pliki:
- `hero.jpg` — duże zdjęcie na górze
- `photo-1.jpg` do `photo-6.jpg` — zdjęcia w galerii

Najprościej: zachowaj dokładnie te nazwy plików. Nie musisz wtedy zmieniać kodu.

## GitHub Pages
1. Utwórz repozytorium na GitHub.
2. Wrzuć `index.html`, `style.css`, `script.js` oraz folder `assets`.
3. Wejdź w Settings → Pages.
4. Wybierz Deploy from a branch → `main` → `/ (root)`.
5. Zapisz. Po chwili GitHub poda adres strony.

## Ważne
Zdjęć z zewnętrznych serwisów nie pobieram automatycznie do paczki — galeria jest przygotowana tak, żebyś mogła wrzucić swoje wybrane fotografie w `assets`.
